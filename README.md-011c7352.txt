# Memory Match - Card Quest

A responsive memory-card game. Match every pair before the timer ends.

## Files

- `index.html`: complete game, including CSS and JavaScript.
- `README.md`: these instructions.

No installation, build command, images, or external libraries are needed.

## Play

Open `index.html` in a modern browser. Match two identical cards. Complete a level, then press Next Level to get a bigger board.

Cards by level: 12, 16, 20, 24, 30, 36, 42, 48, 56, 64, 72, 80.
Level 12 and later keep 80 cards. Bigger boards get more time. On phones, scroll down for large boards.

Controls: New Game restarts from level 1; Pause freezes the timer; Sound toggles audio. The menu contains history, stats and achievements. Scores and history are saved in this browser only. Clear History removes saved history.

## GitHub upload

1. Extract the ZIP. Keep `index.html` and `README.md` at the repository root, not inside an extra folder.
2. Create or open your game repository on GitHub.
3. Choose Add file > Upload files and select both files.
4. Commit changes. If replacing an older game, replace its existing `index.html`.
5. Use your preferred static host to publish the repository. For GitHub Pages, open repository Settings > Pages and select your branch and root folder where available.

The file names must be exactly `index.html` and `README.md`. Remove `.txt` if you save the text-copy versions.

## Encoding

The page declares UTF-8. Its source uses ASCII-safe HTML entities and JavaScript escapes for emoji and symbols, so they display normally without broken text after copying.
